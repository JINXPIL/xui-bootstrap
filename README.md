# 🚀 xui-bootstrap

Автоматизированный скрипт для быстрого и безопасного развёртывания панели **3x-ui** на чистых VPS под управлением **Ubuntu 22.04 / 24.04** и **Debian 11 / 12**.

Скрипт полностью берет на себя базовую гигиену сервера: оптимизирует сетевой стек, настраивает фаервол, конфигурирует донора для маскировки **VLESS Reality**, изолирует порт веб-панели и импортирует готовые шаблоны инбаундов без ручной настройки в UI.

---

## ✨ Возможности

* **Маскировка Reality & Self-steal**:
  * Автоматическая валидация донора (проверка поддержки TLS 1.3 и HTTP/2 через OpenSSL/cURL).
  * Сравнение ASN целевого донора и подсети VPS для защиты от DPI-эвристик.
  * Поддержка режима `selfsteal` (автоподнятие локального сайта-заглушки в Nginx с получением сертификата Let's Encrypt).
* **Сетевая оптимизация**:
  * Автоматическое включение алгоритма управления перегрузками **BBR** и планировщика `fq`.
  * Включение зондирования MTU (`net.ipv4.tcp_mtu_probing=1`).
  * Синхронизация времени по NTP (критично для проверки временных меток в Reality).
* **Безопасность из коробки**:
  * **UFW Firewall**: закрывает снаружи порт панели (доступ только через защищённый SSH-туннель или явное открытие); наружу смотрят только SSH и порты активных инбаундов.
  * **Fail2ban**: развёртывание джейлов с баном за перебор паролей по SSH.
  * Опциональное отключение авторизации по паролю (`SSH_KEYS_ONLY=1`).
* **Изоляция трафика (Anti-Leak)**:
  * Правило маршрутизации Xray `BLOCK_RU=1`: блокирует трафик к `geoip:ru` и доменам `.ru` / `.su` / `.рф` на стороне VPS, предотвращая случайную деанонимизацию и утечки через домашний сегмент.
* **Импорт инбаундов через API**:
  * Автоматический импорт любых протоколов (`vless`, `vmess`, `trojan`, `hysteria2`, `shadowsocks`) из JSON-шаблонов в каталоге `inbounds/`.
  * Автоопределение SSL/TLS при взаимодействии с локальным API 3x-ui.

## ⚡ Быстрый старт

### 1. Клонирование репозитория на сервере

Подключитесь к вашему VPS по SSH и склонируйте проект:

```bash
git clone [https://github.com/JINXPIL/xui-bootstrap.git](https://github.com/JINXPIL/xui-bootstrap.git) && cd xui-bootstrap
```

### 2. Настройка переменных окружения

Скопируйте пример файла настроек в рабочий `config.env`:

```bash
cp config.example.env config.env
nano config.env
```

Базовые параметры для режима **Reality**:

```bash
MASK_MODE=reality
REALITY_SNI=vk.com              # Домен-донор (например, vk.com, yahoo.com)
BLOCK_RU=1                      # 1 — блокировать трафик на RU-ресурсы через сервер
ENABLE_BBR=1                    # 1 — включить TCP BBR
SSH_KEYS_ONLY=0                 # 1 — отключить вход по паролю (требуется настроенный authorized_keys)
```

### 3. Подготовка файла инбаунда

Скопируйте шаблон инбаунда:

```bash
cp inbounds/vless-reality.json.example inbounds/vless-reality.json
nano inbounds/vless-reality.json
```

Заполните поля своими криптографическими ключами X25519:
* `id` — UUID клиента.
* `privateKey` — приватный ключ Reality.
* `publicKey` — публичный ключ Reality.
* `shortIds` — короткий ID хэндшейка (hex).

> Метки `__SNI__` и `__DEST__` заполнять не нужно — скрипт автоматически подставит значения из `config.env`.

### 4. Запуск развёртывания

Сделайте скрипт исполняемым и запустите его:

```bash
chmod +x bootstrap.sh
./bootstrap.sh
```

По завершении работы в терминале появится сводка с логином и паролем от панели, строкой для проброса SSH-туннеля и сгенерированными `vless://` ссылками для клиентов. Полный отчёт сохраняется в файл `/root/xui-result.txt`.

## 🔐 Доступ к веб-панели через SSH-туннель

По умолчанию в целях безопасности порт веб-панели не открывается в интернет. Доступ к панели осуществляется через локальный защищённый порт:

1. На вашем локальном компьютере выполните команду проброса туннеля (в PowerShell или Терминале):

```bash
ssh -N -L 8080:127.0.0.1:<ПОРТ_ПАНЕЛИ> root@<IP_СЕРВЕРА>
```

2. Откройте в браузере:
```text
[https://127.0.0.1:8080/](https://127.0.0.1:8080/)<WebBasePath>/
```

## ⚙️ Переменные конфигурации (`config.env`)

| Переменная | Значение по умолчанию | Описание |
| :--- | :---: | :--- |
| `MASK_MODE` | `reality` | Режим маскировки трафика: `reality` или `selfsteal`. |
| `REALITY_SNI` | — | Домен-донор для TLS 1.3 Reality. |
| `REALITY_DEST` | `$REALITY_SNI:443` | Целевой порт для проксирования невалидных хэндшейков. |
| `DOMAIN` | — | Собственный домен (требуется только для режима `selfsteal`). |
| `BLOCK_RU` | `1` | Блокировка российских подсетей и доменов в маршрутизации Xray. |
| `ENABLE_BBR` | `1` | Активация алгоритма управления перегрузками TCP BBR. |
| `SSH_KEYS_ONLY` | `0` | Отключение авторизации по паролю по SSH (`1` — только ключи). |
| `XUI_VERSION` | `latest` | Фиксация конкретного тега релиза 3x-ui (по умолчанию последний). |
| `XRAY_VERSION`| — | Фиксация версии бинарника Xray. |

## 🛡️ Безопасность

* Файлы `config.env` и `inbounds/*.json` занесены в `.gitignore` и никогда не попадут в публичный репозиторий.
* Все клиентские ссылки и временные выгрузки сохраняются локально на VPS с правами `600`.
